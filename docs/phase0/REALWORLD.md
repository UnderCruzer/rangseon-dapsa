# 실제 건물·도로 + 월드모델

사용자 요구: 실제 데이터에 기반한 건물과 도로가 나와야 하고, 월드모델을 사용한다. 점토 미니어처 방향은 철회한다. 현재 변경은 Phase 0의 데이터·기술 검토이며 **데이터 승인, 모델 실행 또는 앱 제작 완료가 아니다**.

## 확정한 기준

- 건물 위치·윤곽·높이·도로 형상은 실제 공간 데이터에서 가져온다. 누락된 건물을 생성해서 실제 건물이라고 표시하지 않는다.
- 도로 표시용 표면과 경로 계산용 그래프를 구분한다. PLATEAU의 도로 표면이 곧 보행 가능 네트워크는 아니다. 기존 OSM 보행 연결과 접근 제한을 함께 검토한다.
- 월드모델 사용을 일반 3D 지도나 Gaussian Splatting 렌더러만으로 대체했다고 주장하지 않는다. 실제 모델 실행, 모델/가중치 버전, 입력 자료, 출력과 검수 기록이 있어야 사용 완료다.
- 생성·복원 결과는 관측 자료와 별도 관리한다. 원본 지리 데이터는 덮어쓰지 않는다. 건물·교차로의 위치와 연결을 바꾼 결과는 실제 장소 탐색에 채택하지 않는다.
- 영상 출력만 얻은 상태는 자유 시점 3D 탐색이 아니다. 앱 조작, 거리·경로 계산은 실제 3D 장면에서 이루어져야 한다.

## 실제로 확인한 입력 자료

공식 [PLATEAU 카탈로그](https://api.plateauview.mlit.go.jp/datacatalog/plateau-datasets)를 수집했다. 미나토구(13103)의 2025년 건물 LOD1/2/3 텍스처 데이터와 도로 LOD3 텍스처 데이터가 등재되어 있고, 네 개 tileset.json 응답을 확인했다. 각 root bounding region은 OSM 도쿄타워 대표 좌표를 포함한다. 이는 **개별 객체나 1.5km 전 구역의 상세 모델 존재를 검증한 것은 아니다**.

`data/realworld/availability.json`에 관련 카탈로그 8행과 검사 결과, `sources.json`에 실제 URL·수집시각·원본 SHA-256을 남겼다. 원본 JSON은 gzip으로 무손실 보관한다. 배포용 대용량 타일이나 모델 가중치는 아직 받지 않았다. 카탈로그의 2025는 정비 연도이며 모든 사진·측량의 촬영일로 간주하지 않는다. 개별 데이터 이용조건, 촬영일, 정밀도, 좌표·높이 기준은 추가 확인 대상이다.

기존 OSM 원본·Day 1 후보 장소·영업시간 대조는 유지한다. OSM 높이 누락을 임의 층고로 채우는 대신 PLATEAU 객체와 실제 위치를 대조할 예정이다.

## 모델 역할과 선정 상태

| 구성 | 후보와 용도 | 확인한 한계 / 상태 |
|---|---|---|
| 실제 공간 기준 | PLATEAU 건물·도로 + OSM 경로 | 메타데이터만 확인. 실제 객체 대조·시각 검수 전 |
| 월드모델 | NVIDIA Cosmos 3의 공간 제어 기반 Transfer 검증 | 공식 예제가 depth/edge/segmentation 입력을 지원. 출력은 생성 영상이며 도쿄 지리 보존을 보장하지 않음. **후보, 미실행** |
| 실제 촬영 자료의 3D 복원 | MapAnything Apache 모델 + gsplat 후보 | MapAnything는 3D 복원 모델이며 자체를 월드모델이라고 부르지 않음. 직접 확보하거나 허용된 실제 다중 시점 입력이 필요. **미실행** |
| 인터랙티브 앱 표시 | 기존 Cesium·3D 뷰어 활용 검토 | 표시 도구 자체는 월드모델이 아님. 모델 결과가 좌표 정합 검수를 통과한 경우만 결합 |

NVIDIA의 [공식 Transfer 예제](https://github.com/NVIDIA/cosmos/blob/main/cookbooks/cosmos3/generator/transfer/run_video_transfer_with_vllm_omni.ipynb)는 공간 조건을 사용하지만 측량 수준 위치 보존을 약속하지 않는다. 따라서 “공식 geometry → 조건 입력 → 월드모델 출력 → 원본 대조”가 검증 계획이다. 출력의 지리 변형을 막는다는 보장은 아직 할 수 없다. 원본을 바꾸지 않는 구조와 결과 채택 검사가 필요하다. 모델이 불필요한 건물·문·도로를 추가하면 해당 결과는 불합격 처리한다.

앞서 언급한 HY-World 2.0은 [공개 라이선스](https://github.com/Tencent-Hunyuan/HY-World-2.0/blob/main/License.txt)의 Territory에서 한국이 제외되어 기본 채택 후보에서 제외했다. 별도 권한을 얻었다고 가정하지 않는다. [MapAnything](https://github.com/facebookresearch/map-anything)의 Apache 체크포인트와 CC-BY-NC 기본 체크포인트는 구분해야 한다. 실제 실행 전 선택한 정확한 가중치·부속 모델의 조건을 기록한다.

## 데이터 승인 이후 제안하는 최소 실증

1. 도쿄타워와 인접 교차로 한 구간에서 PLATEAU 객체를 OSM 및 실제 사진과 대조한다. 지표 고도·좌표계·건물 ID·도로 높이·출입구·자료 시점의 차이를 기록한다.
2. 실제 자료가 확인된 범위에서만 고정 카메라 경로와 depth/edge 조건을 만든다. 출처 없는 텍스처나 가상의 장소 사진을 실제 입력으로 사용하지 않는다.
3. 준비된 GPU 환경에서 월드모델을 실제 실행하고 입력·출력·모델 버전·설정·시간·비용을 기록한다. 현재 GPU 실행 환경, 재구성용 다중 시점 자료는 확보 여부 미확인이다.
4. 원본과 결과를 같은 시점으로 대조한다. 타워·건물 윤곽·교차로 수와 연결·보행 공간의 변형, 프레임 간 흔들림을 검사한다. 허용 오차는 원본 정밀도 확인 후 정하며 현재 수치로 지어내지 않는다.
5. 결과를 사용자에게 보여주고 실제 공간의 식별 가능성과 기술 적합성을 승인받는다. 실패하면 원인을 공개하고 모델·입력을 재검토한다. 합성 영상을 3D 성공으로 대체하지 않는다.

낮→밤도 별도 검증 대상이다. 낮 촬영 텍스처를 어둡게 하거나 모델이 야경을 생성한 결과는 관측된 실제 야경이 아니다. 실제 야간 자료가 없으면 시뮬레이션임을 표시한다. 점토 캐릭터·장난감 소품·임의 차량 애니메이션은 새 기준에 포함하지 않는다.

## 재현

```sh
# 초기 메타데이터 수집 또는 명시적 갱신
python3 -B scripts/phase0/realworld_sources.py --fetch
# 원본 해시 확인 및 동일 결과 재생성; 네트워크 없음
python3 -B scripts/phase0/realworld_sources.py
```

현재 확인 완료: 공식 카탈로그·타일 manifest 접근, 원본 해시 및 재생성. 미완료: 실제 모델 추론, 원본 대비 정확도, 실사 품질, 모바일 성능. 기존 승인 경계는 유지하며 이 문서는 다음 단계 실행 승인을 대신하지 않는다.

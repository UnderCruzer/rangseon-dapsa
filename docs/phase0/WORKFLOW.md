# 도쿄 점토 미니어처 — 승인형 제작

핵심 메시지: **실제 도쿄 데이터에서 완성된 여행 앱까지.**

2026-10-03 사용자 명세가 이 도쿄 작업의 기준이다. 기존 국내 여행 중심 방향과 별개로 도쿄타워 반경 1.5km를 검증한다. 브랜드 상표·캐릭터 형태를 사용하지 않는다. 이전 LEGO 시안은 사용하지 않는다.

| 단계 | 산출물 | 다음 단계 조건 | 태그 |
|---|---|---|---|
| 0 데이터 | 원본·출처·CSV·가공 JSON·검토 페이지 | 사용자의 ‘데이터 승인’ | phase-0-data |
| 1 스타일 | style.md, 실제 지형 정지 렌더 4장 | ‘스타일 승인’ | phase-1-style |
| 2 에셋 | 코드 생성 소품·관절 캐릭터·낮밤 검수 시트 | ‘에셋 승인’ 및 ‘앱 제작 시작’ | phase-2-assets |
| 3 앱 | 실제 좌표 3D, 낮밤·동선·애니메이션·UI | 앱 검수 승인 | phase-3-app |
| 4 검증 | 모바일 조작·중급 폰 30fps 측정 | 완성 승인 | phase-4-functional |
| 5 영상 자료 | BEFORE/AFTER, 시간 슬라이더 녹화 지원 | 자료 승인 | phase-5-campaign |

각 단계는 이슈 → 브랜치 → PR. 태그는 검토 가능한 산출물 버전을 가리키며 **승인을 의미하지 않는다**. 승인 내역은 실제 사용자 메시지를 받은 후 기록한다. 기존 PR #18~20은 이번 지시에 의해 자동 머지하지 않는다.

현재: Phase 0 진행 / 데이터 미승인. Phase 1 이상 미착수. Higgsfield 생성·3D 도구는 후속 승인된 단계에서 사용한다. Phase 0에서는 이미지를 생성하지 않는다. 앱 제작에 특정 모델이나 외부 서비스가 쓰였다고 실제 실행 없이 기록하지 않는다.

## Phase 0 데이터 계약

- 원본 응답 bytes + SHA-256 + 실제 UTC fetched_at 보관. 기본 재실행은 네트워크 없이 고정 스냅샷을 재사용한다. 최신 재수집(`--refresh`)은 다른 관측 버전이며 같은 값이 보장되지 않는다.
- raw CSV 요구 열: `name,category,lat,lng,opening_hours,duration_min,source,source_url,license,fetched_at`. OSM에 없는 값은 빈칸. 화면에서만 ‘미확인’으로 표기. 문자열/태그를 정규화하거나 영업시간을 덮어쓰지 않는다.
- category는 원본 `key=value` 태그 목록을 보존한다. way/relation의 대표점은 raw 좌표로 사칭하지 않고 가공 JSON에서 계산 방법을 표시한다. 원본 전체 geometry·tags는 JSON에 남긴다. CSV 행과 OSM 객체 매핑은 별도 파일.
- OSM `building:levels`를 임의 층고로 height로 바꾸지 않는다. height 미확인 건물, 미매핑 가로수·신호 주기를 창작하지 않는다. OSM에는 지표 고도 모델이 없으므로 ‘지형’은 지물 데이터이며 DEM은 미확인.
- Wikidata CC0는 연결된 이미지에 자동 적용되지 않는다. Commons 파일별 라이선스·저작자·출처를 별도로 확인한다. 미확인 이미지는 앱 번들 금지.
- 장소 체류시간은 실제 장소 속성이 아니라 사용자 검토용 계획 제안. `duration_min` raw 값과 분리하고 제안 근거를 남긴다. 평점은 수집하지 않는다.
- 보행 거리는 실제 OSM node 연결 그래프의 최단거리. 도보 시간은 걷는 속도를 두어 산출하는 **추정**. 출입구 연결이 검증되지 않으면 방문지와 그래프 사이의 미확인 연결 거리를 따로 공개한다.
- 지하철은 공식 역 순서를 먼저 확인한다. 승차시간·대기시간을 알 수 없으면 null. 택시는 회전 제한/접근 제한 검증 없이 ‘실제 운행 경로’라고 하지 않는다.
- 여행 날짜 미정이면 일출·일몰과 방문 절대시각은 null. 야경은 ‘일몰 이후’라는 제약만 기록한다. 임의 날짜로 확정 일정처럼 보여주지 않는다.
- raw 검토 페이지는 `review/phase0/`로 앱 빌드와 분리한다. 여행 앱 UI나 3D 인터랙션은 이 단계에서 만들지 않는다.

# 서울 Phase 0 — 남산 N서울타워 실데이터 (#28)

2026-10-04 사용자 지시: 도쿄는 데모로 남기고 서울을 새로 시작한다. 목표는 "실제 가기 전 직접 가 있는 듯한 현장감". 실제 3D 데이터로 위치·형상을 고정하고 월드모델로 실사화하는 도쿄 방식([REALWORLD.md](../phase0/REALWORLD.md), [COSMOS.md](../phase1/COSMOS.md))을 재사용한다. 데이터 계약은 도쿄 [WORKFLOW.md](../phase0/WORKFLOW.md)의 Phase 0 계약을 그대로 따른다.

## 범위

앵커: OSM relation/16474080 `남산서울타워` (Q69134), 대표 좌표 37.5512605, 126.98822 (출입구 아님). 반경 1,500m, 보행 연결용 highway는 2,200m.

## 국내 3D 원천 조사 (2026-10-04)

| 원천 | 내용 | 이용 가능성 | 상태 |
|---|---|---|---|
| **S-Map** (서울시 디지털트윈) | 서울 전역 사진 텍스처 3D, 약 60만 동, CityGML ID 체계 | 웹 뷰어와 오픈랩(로그인, QGIS 플러그인) 안에서 활용. 원본 메시 외부 다운로드 경로는 찾지 못함 | **서울시 문의 필요**. 뷰어 타일 무단 수집 금지 |
| **브이월드 3D** | LoD1 전국, LoD3~4 주요 도심 텍스처 | 국가공간정보 보안관리규정상 '공개제한'. 허가 없는 복제·출력 불가. 3D Open API는 2019년 폐쇄 | 사용하지 않음 |
| **GIS건물통합정보** (국토교통부) | 전국 건물 윤곽 + 건축물대장 지상층수(`GRND_FLR`)·높이(`HEIGHT`), SHP | 공공누리 제1유형(출처표시), 무료. 브이월드·공공데이터포털 로그인 후 다운로드 | **사용자 다운로드 필요** |
| **DEM** | 국토지리정보원 수치표고모델(5m), S-Map 오픈랩 1m DEM | 포털 로그인 필요. 대안: Copernicus GLO-30(30m, 공개) | 미수집 |
| **항공사진** | 브이월드 WMTS (PR #20) | `VWORLD_KEY` 필요. 보안시설 가림 처리됨 | 키 대기 |
| Google 실사 3D | — | 국내 3D 반출 제외로 없음 | 해당 없음 |

남산은 해발 약 262m의 산이라 **지형이 장면을 좌우한다**. 도쿄보다 DEM 해상도가 중요하다.

## 국내 처리 원칙

2026-02-27 정밀지도 국외반출 조건부 허가에서 3D 정보는 제외됐고, 국내 서버 가공이 조건이었다. 이에 따라 국내 3D·고해상도 영상 원천을 국외 클라우드(RunPod 등)로 보내지 않는다. 월드모델은 국내 장비(사용자 데스크탑 RTX 4070 Super, 12GB)에서 실행한다. 정확한 법적 범위는 미확인이므로 보수적으로 적용한다. OSM·Copernicus 등 해외 공개 원천은 이 제한 대상이 아니다.

## OSM 스냅샷 결과

`scripts/seoul/collect_osm.py` (네트워크 없이 기본 재실행은 저장 bytes 해시 검증). `data/seoul/sources.json`에 URL·쿼리·UTC 수집시각·SHA-256.

- 반경 1.5km 핵심 객체 67,629개, 건물 5,238동.
- **높이 정보: `height` 3.2%, `building:levels` 8.2%, 둘 중 하나 8.5%.** OSM만으로는 3D 건물 높이를 세울 수 없다. 높이는 GIS건물통합정보로 채우고, 없는 값은 미확인으로 남긴다(임의 층고 금지).
- 보행 관련 highway: footway 1,282, steps 428, path 403, pedestrian 243 등. 남산 산책로·계단 연결은 실제 접근 제한 검증 전이다.
- Day 1 후보 장소 OSM 존재 확인(타워 기준 거리): 남산팔각정 67m, 남산 케이블카 152~567m, 안중근의사기념관 732m, 백범광장 881m, 해방촌 889m, 남산골한옥마을 정문 1,051m, 명동역 1.1km, 명동대성당 일대 1.34km.

## 다음 단계

1. 사용자: GIS건물통합정보(서울 중구·용산구) SHP 다운로드, `VWORLD_KEY` 등록

3. Day 1 동선 제안(예: 명동 → 남산골한옥마을 → 케이블카 → N서울타워 → 해방촌)과 OSM 보행 거리 추정
